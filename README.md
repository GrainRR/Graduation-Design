# 学生社团管理系统（Django + SQLite）

基于你给出的需求分析实现的完整课程项目，包含普通成员、社团管理员、高级管理员三类角色，数据库使用 SQLite。

## 技术栈

- Python 3 + Django
- SQLite（默认 `db.sqlite3`）
- Django Template（服务端渲染）

## 已实现模块

- 账号与权限：学号/手机号/邮箱登录、个人资料、修改密码、重置密码、RBAC 角色控制
- 多社团：全员「社团列表」浏览名称/简介/图标；社团管理员绑定所属社团；成立新社团审批后创建新社团记录
- 高级管理员在社团详情页可查看该社公告、简介、成员（社长/副社长彩色标识），并可用「整页编辑模式」一次性保存社团信息与各公告正文
- 社团信息与组织架构：按所属社团隔离；部门岗位维护、任职分配（岗位仅社长/副社长）
- 通知公告：发布范围（全员/部门/角色）、发布与撤回、已读标记、阅读统计基础能力
- 活动管理：社长/副社长新建活动后须「提交发起审批」，高级管理员通过后方可发布；成员报名/签到；统计
- 入社申请与审批：成员提交申请，**仅社团管理员（社长体系）**审核；高级管理员不参与入社审批
- 成立社团申请：普通成员提交成立社团申请，高级管理员审批，通过后发放社团管理员权限并任命社长
- 非功能落地（基础）：事务控制与并发保护（报名、签到、审批）
